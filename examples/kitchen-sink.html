Toggle group

.ntn-toggle-group

Segmented control for picking a value: a filter, a date range, a view of the same content. Each button carries aria-pressed; add data-multi to the group for independent toggles. --pill draws the choice as a raised pill that slides between options; it is for single choice only. If each option shows different content, that is tabs; inside a form, use the segmented radio group.

Select

.ntn-select

A native <select>, restyled — smallest footprint, and it gets the platform picker on mobile for free. Add data-ntn-select and nocturne.js draws a listbox over it instead (search with data-ntn-search, an empty state with data-ntn-empty), while the native select still posts and fires change. Reach for Dropdown when options need descriptions, icons or chips.

Glass

.ntn-glass .ntn-glass--flat .ntn-glass--clear .ntn-glass--frosted .ntn-ambient

Translucent, blurred surfaces for a page that sits over artwork or a gradient. On a card, stat, accordion or sidebar it glazes that surface; on a wrapper it glazes every surface inside. ntn-ambient, first inside .ntn-app, is a static accent glow to sit them on; point --ntn-ambient-image at your own artwork. ntn-glass--flat drops the lit top edge, which suits the plain glow. Below, flat glass over the glow alone, then glass over a photo as --ntn-ambient-image (dimmed and faded, for a page where text also sits on the backdrop), and over the same photo as --ntn-background-image (full strength), then ntn-glass--clear and ntn-glass--frosted beside the default, which thin or thicken the fill. Then the placements, which move the glow to an edge, a corner or the centre; the tones, which tint it (or set --ntn-ambient-glow); and two ambients stacked for two lights. The droplet in the top bar turns glass on for this whole page, with the photo as the ambient image.

Tabs

.ntn-tabs

Roving tabindex: one tab is in the tab order and ← → (↑ ↓ when vertical) moves between them, home/end jump to the ends. data-ntn-panel="#id" points a tab at its panel; the indicator is one element that slides. Overflowing tabs scroll, and the selected one is kept in view. Every tab switches a panel; to pick a value (a range, a view, a filter), use a toggle group.

JavaScript

nocturne.js

Optional and dependency-free. It wires itself up on import and listens on the document, so markup opts in with data-ntn-* attributes and nothing else; each section's Code shows the attributes its example needs. Without the script every component still renders; tabs, dialogs, dropdowns, pickers, toasts and table paging are what it adds.
