Tooltip

.ntn-tooltip

CSS only: wrap the trigger, add __bubble as a sibling. Opens on hover and keyboard focus, after a 90 ms delay so a mouse crossing the row stays quiet. Four sides, --start/--end alignment, --wrap for a sentence.

Default placement Below the trigger To the left To the right
Retention Events older than 30 days are rolled up hourly and dropped from the live index. Command palette⌘K Aligned to the trigger's left edge — for a wide bubble on a narrow control.

Border effects

.ntn-edge

A border treatment that composes onto anything — a card, a panel, a toolbar, a bare div. ntn-edge alone is the default hairline; ntn-card--glow and ntn-card--processing stay as card shorthands.

A hairline and the standard radius. The baseline every effect starts from.

Glow

Accent hairline, halo, and a colour bleed from the top edge. The one element read first.

Processing

A light travels the edge and an exterior glow orbits with it. Remove the class when the job lands.

Tabs

.ntn-tabs

Roving tabindex: one tab is in the tab order and ← → (↑ ↓ when vertical) moves between them, home/end jump to the ends. data-ntn-panel="#id" points a tab at its panel; the indicator is one element that slides. Overflowing tabs scroll, and the selected one is kept in view.

Menu

.ntn-menu

The dropdown surface for action menus and custom pickers — position it yourself. Nest one by wrapping a row and its panel in .ntn-menu__sub: hover and focus open it with no script, and nocturne.js adds ← → traversal plus an edge flip.

This file

Two levels deep here. A submenu row carries aria-haspopup and a __caret; the panel inside it is just another .ntn-menu. Dividers now use --ntn-border-default, so they read on the menu surface.

Dropdown and popover

.ntn-dropdown

A trigger with aria-haspopup plus a panel. nocturne.js opens the panel in the top layer, so even this flush (clipping) card can't cut it off. Arrow keys, Home/End, Escape and outside clicks work.

Progress steps

.ntn-steps

One attribute drives everything: data-state="complete | current | upcoming" paints the marker, the labels and the connector behind it. Wrap a step's content in __hit to make it clickable; data-ntn-steps on the list walks the states and fires ntn:stepchange.
